# ربات تلگرامی آپلودر فایل‌ها

ربات تلگرامی پیشرفته با امکانات کامل برای آپلود، مدیریت و اشتراک‌گذاری انواع فایل‌ها

## ویژگی‌های اصلی

✅ **آپلود و مدیریت فایل‌ها**
- پشتیبانی از تمام نوع رسانه‌ها (عکس، ویدیو، صوت، GIF، استیکر، اسناد)
- نمایش لیستی و اسلایدی رسانه‌ها
- جستجوی پیشرفته
- سیستم پوشه‌بندی سلسله‌مراتبی
- ویرایش کپشن و حذف گروهی

✅ **امنیت و دسترسی**
- قفل فروارد (ضد کپی)
- قفل ضد فیلتر (حذف خودکار)
- جوین اجباری کانال‌ها
- رمزعبور برای رسانه‌ها
- محدودیت دانلود

✅ **سیستم اشتراک و پرداخت**
- ۵ روش پرداخت (زرین‌پال، زیبال، کارت به کارت، ارزهای دیجیتال، Telegram Stars)
- پلن‌های اشتراک قابل تنظیم
- مدیریت تراکنش‌ها

✅ **پنل مدیریتی**
- مدیریت کاربران و ادمین‌ها
- آمارگیری مفصل
- ارسال پیام همگانی
- بکاپ و ریستور

## نصب خودکار

```bash
# 1. دانلود وابستگی‌ها
composer install

# 2. دسترسی دهید
chmod 755 public/install.php

# 3. در مرورگر باز کنید
# http://yoursite.com/public/install.php
```

## نصب دستی (برای هاست‌های اشتراکی بدون Composer)

تمام فایل‌ها آماده‌اند و نیازی به نصب وابستگی خارجی ندارند.

## ساختار فایل‌ها

```
├── public/
│   ├── webhook/
│   │   └── index.php          # ورودی Webhook
│   ├── admin/
│   │   ├── index.php          # داشبورد ادمین
│   │   ├── users.php          # مدیریت کاربران
│   │   ├── media.php          # مدیریت فایل‌ها
│   │   └── settings.php       # تنظیمات
│   ├── install.php            # نصب خودکار
│   └── .htaccess              # تنظیمات Apache
├── src/
│   ├── Controllers/           # کنترلرها
│   ├── Models/                # مدل‌های دیتابیس
│   ├── Helpers/               # توابع کمکی
│   └── Config/                # فایل‌های تنظیم
├── database/
│   └── schema.sql             # ساختار دیتابیس
├── logs/                      # فایل‌های لاگ
├── storage/                   # فضای ذخیره‌سازی موقت
└── .env.example               # مثال فایل تنظیمات محیطی
```

## پیش‌نیازها

- PHP 8.1 یا بالاتر
- MySQL 5.7 یا بالاتر
- توکن بوت تلگرام
- دسترسی cPanel یا SSH برای تنظیم Webhook
